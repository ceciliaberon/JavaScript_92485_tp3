Este proyecto utiliza el mismo repositorio de la entrega anterior, ya que la Entrega 4 toma como base el trabajo realizado en la Entrega 3 y agrega nuevos contenidos vistos en clase.
Entrega 3

En la entrega anterior se trabajaron conceptos relacionados con funciones en JavaScript, entre ellos:

Declaración de funciones.
Expresión de funciones.
Parámetros y argumentos.
Retorno de valores con return.

A partir de estos contenidos se desarrolló un simulador sencillo relacionado con la cantidad de días de entrenamiento semanal.

Entrega 4

Para esta entrega se amplió el proyecto incorporando el uso de arrays y distintos métodos para trabajar con sus elementos.
